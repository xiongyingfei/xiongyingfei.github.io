# 课后更新网站

2026 秋季软件分析：课次数据在 `_data/SA_new/_2026.yaml`，页面在 `SA_new/2026/`；独立项目材料在 `SA_new/2026/materials.md`。

1. 判定材料属于已上课课次还是独立项目说明。将新 PDF 放入 `SA_new/2026/slides/`，读取与当前网站更新有关的标题、题目或项目要求。
2. 更新课次时，修改 YAML 的 `lectures`：上课日期、课件标题及文件名、完整作业题目、截止时间。截止时间遵循项目根目录 `AGENTS.md` 的默认规则及延期例外；用户本次明确指定的时间优先。每条主要求一个 `text`；提醒、排除清单和“无作业”等说明项也用 `text`，并加 `note: true`，让页面区别呈现且保留原有顺序。不要把教学计划 `schedule` 当成已发布课次。
3. 更新独立项目材料时，在 `materials.md` 链接原文件，按本次范围补充必要说明；先核对现有项目表和手册入口，不无依据地覆盖已发布日期或要求。除非明确作为课次发布，不为项目说明另添 `lectures`。
4. 核对受影响的题目、日期、要求和链接，提交改动；已获发布授权时推送，确认上线后给出页面链接。

页面规则：

- 作业页直接展示完整题目和截止时间，不放幻灯片链接，也不加“已在教学网发布”“参见课件”等说明。`assignments.md` 只保留通用规则和标题，题目由 YAML 渲染。
- 作业主要求统一不编号，每条用轻量左线与留白区分；说明保留原顺序，不使用左线。单条和多条使用同一版式。
- 首页通知由 `_includes/announcements.html` 生成，每课一行：`日期 幻灯片标题链接 作业链接 · 截止日期`。不加中括号，无作业则省略作业部分；窄屏自然换行。
